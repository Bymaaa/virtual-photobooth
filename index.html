Gagal Akses Kamera? 💡

Jika kamera gelap/tidak muncul, ikuti langkah cepat berikut:

Di Mobile Browser (Chrome/Safari):
  1. Klik ikon Kunci / Gembok / Tune 🔒 di sebelah kiri alamat URL atas.
  2. Pilih menu Izin Situs (Permissions).
  3. Ubah status Kamera (Camera) menjadi Izinkan (Allow).
  4. Refresh / Muat ulang halaman web.

Tips Collab: Pastikan HP Host dan Guest tidak sedang menggunakan kamera di aplikasi lain (seperti WhatsApp/Instagram) saat berfoto.

Tentang Kabin Foto
